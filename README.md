## 双模态协同诊断模型：伪模态生成与坐标融合驱动的糖尿病视网膜病变分类

### 项目概述

本项目实现了一个基于深度学习与迁移学习的糖尿病视网膜病变（Diabetic Retinopathy, DR）多级分类框架。通过利用在 ImageNet 上预训练的模型（EfficientNet ），结合针对医学影像优化的预处理技术，实现对眼底彩照的高精度自动分级（0-4级）。

### 方法简介

1. 提出了一种基于纯 CPU 环境的高效血管形态拓扑提取方法： 设计了一套精密的全形态学处理流水线，通过集成多尺度滤波（Multiscale Filtering）与精细化形态学算子，能够在不依赖 GPU 算力的情况下，从复杂底片中精准提取具有连通性的视网膜血管二值图。该方法不仅为模型提供了关键的解剖走势指引，更为医疗边缘设备的实时病理分析奠定了计算基础。
2. 构建了兼顾浅层纹理与深层语义提取的轻量化双分支架构： 针对糖尿病视网膜病变（DR）的复杂特征，本研究设计了一种兼具理性与效率的模型拓扑。该架构通过双分支结构并行捕捉病理细节与几何结构，并创新性地引入了自适应门控机制（Adaptive Gating）与通道注意力模块（SE Block）实现特征的协同重标定。这种设计确保了模型在保持轻量化、易部署特性的同时，能够实现对关键特征的自动筛选与深度挖掘。
3. 通过多尺度数据集与独立外部验证确立了模型的稳健泛化性能： 为客观评估方案的泛化边界，本研究在多种规模的基准数据集上执行了严格的性能评估，并引入独立外部验证集对模型有效性进行审视。实验结果一致证明，所提方案在面对不同采集设备与病理分布时，均展现出优异的 DR 检测精度与分类一致性，具备高度的临床泛化潜力。

### 数据集

主实验中采用的数据集是aptos2019。
泛化实验中采用的数据集是Kaggle DR。

### 分类任务
类别：5类分级（国际临床标准）：

0：无病变 (No DR)

1：轻度非增殖性 (Mild NPDR)

2：中度非增殖性 (Moderate NPDR)

3：重度非增殖性 (Severe NPDR)

4：增殖性 (Proliferative DR)
